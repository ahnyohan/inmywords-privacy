내말로 개인정보처리방침

시행일: 2026년 11월 12일

내말로(이하 “앱”)는 한국어로 말한 문장을 영어로 바꿔 연습하는 개인용 학습 앱입니다. 이 방침은 앱이 어떤 정보를 다루고, 어디에 두며, 언제 밖으로 보내는지 설명합니다.

한눈에 보기

  • 회원 가입이 없고, 개발자가 운영하는 서버가 없습니다. 개발자는 사용자의 정보를 받지 않습니다.
  • 기록(문장, 녹음, 설정)은 사용자의 기기 안에만 저장됩니다.
  • 음성 인식은 기기 안에서 처리됩니다. 녹음이 밖으로 보내지지 않습니다.
  • 사용자가 AI 번역(Claude API)을 직접 켠 경우에만 번역할 문장이 Anthropic으로 전송됩니다.
  • 광고, 분석, 추적 도구를 쓰지 않습니다.

1. 다루는 정보와 저장 위치

정보내용과 저장 위치
말한 문장받아 적은 한국어 문장, 번역된 영어 문장, 단어, 일기, 학습 기록. 기기 안 앱 저장소(데이터베이스)에 저장됩니다.
녹음사용자가 녹음 버튼을 눌렀을 때 녹음한 소리. 기기 안 앱 저장소에만 저장되고 밖으로 보내지 않습니다.
설정학습 시작일, 고른 AI 모델, 재생 설정 등. 기기 안에 저장됩니다.
API 키사용자가 AI 설정에 넣은 Claude API 키. 기기 안의 백업 제외 영역에만 저장되며, 클라우드 백업이나 기록 내보내기 파일에 들어가지 않습니다.

앱은 이름, 연락처, 위치, 기기 식별자, 광고 ID를 수집하지 않습니다.

2. 사용하는 권한

  • 마이크: 녹음 버튼을 누른 동안에만 말을 받아 적고 녹음합니다.
  • 인터넷·네트워크 상태: 사용자가 AI 번역을 켠 경우 Claude API를 부르는 데에만 씁니다.
  • 포그라운드 서비스·절전 중 잠깐 깨우기·부팅 후 실행: 홈 화면 위젯을 기기 안에서 새로 고치는 데에만 씁니다.

3. 밖으로 보내는 경우

아래 경우 말고는 앱이 정보를 기기 밖으로 보내지 않습니다.

  • AI 번역(Claude API): 사용자가 AI 설정에서 자신의 API 키를 넣고 AI 번역을 쓰면, 번역·설명·일기 다듬기에 필요한 문장(한국어 문장, 상황 설명, 영어 문장, 일기 날짜와 문장)이 Anthropic, PBC로 전송됩니다. 녹음과 API 키 외의 설정은 보내지 않습니다. 전송된 내용은 사용자의 API 계정에서 처리되며 Anthropic의 개인정보처리방침을 따릅니다.
  • 다른 AI 앱으로 보내기: 사용자가 [공유하기]로 요청문을 ChatGPT, Claude 앱 등 다른 앱에 보내면, 그 내용은 사용자가 고른 앱으로 넘어가고 그 앱의 방침을 따릅니다. 이 방식에서 내말로는 인터넷을 쓰지 않습니다.
  • 기록 내보내기: 사용자가 [기록 내보내기]를 누르면 기록과 녹음이 담긴 파일을 사용자가 고른 위치에 저장합니다. API 키는 들어가지 않습니다.
  • Android 백업: 기기의 Google 백업이 켜져 있으면 Android가 앱의 데이터베이스와 설정을 사용자의 Google 계정에 백업할 수 있습니다. 녹음과 API 키는 포함되지 않습니다. 기기 설정에서 끌 수 있습니다.

음성 인식과 소리 내어 읽기(TTS)는 기기에 설치된 Android 음성 기능을 사용합니다. 음성 인식은 기기 안 인식만 쓰며, 앱이 녹음을 다른 서버로 보내지 않습니다.

4. 제3자 제공과 처리 위탁

개발자는 사용자의 정보를 받거나 다른 곳에 제공하지 않으며, 처리를 위탁하지 않습니다. 위 3번의 전송은 사용자가 직접 켜거나 고른 경우에만 일어납니다.

5. 보관 기간과 지우기

  • 정보는 사용자가 지우거나 앱을 삭제할 때까지 기기에 남습니다.
  • 앱 안에서 문장, 단어, 녹음을 지울 수 있습니다. 앱을 삭제하면 기기 안의 앱 데이터가 모두 지워집니다.
  • API 키는 AI 설정에서 지울 수 있습니다.
  • Google 계정에 백업된 데이터는 Google 계정의 백업 관리에서 지울 수 있습니다.

6. 사용자의 권리

모든 정보가 사용자의 기기에 있으므로, 사용자는 앱에서 언제든 정보를 보고, 고치고, 내보내고, 지울 수 있습니다. 개발자가 따로 가지고 있는 정보는 없습니다.

7. 안전을 위한 조치

  • 데이터는 Android 앱 전용 저장소에 두어 다른 앱이 읽을 수 없습니다.
  • Claude API와의 통신은 암호화(HTTPS)됩니다.
  • API 키는 로그나 백업에 남기지 않습니다.

8. 아동

이 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 정보를 따로 수집하지 않습니다.
